# Bread-Winner
Developed a hybrid AI resume optimizer leveraging XGBoost and TF-IDF for predictive match scoring, alongside Google Gemini for generative content enhancement. Built with a FastAPI backend and Streamlit frontend, the full-stack application is deployed via GitHub to Hugging Face Spaces for seamless public accessibility.
